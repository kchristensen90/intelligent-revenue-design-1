# Intelligent Revenue · App Redesign Prototype

A clickable design prototype for a redesigned Intelligent Revenue hotel revenue analytics app, built as a single self-contained HTML file.

## Live demo

Once GitHub Pages is enabled, the prototype will be live at:
`https://[your-username].github.io/[repo-name]/`

## What this is

A working interactive prototype showing the redesigned UI for Intelligent Revenue — informed by the 2026 design language of best-in-class B2B SaaS apps (Linear, Stripe, Notion, Gong). All data is mocked. No backend, no API calls.

Features demonstrated:
- Bento grid Home page with sparklines and an editorial AI briefing
- Light and dark mode (toggle in top-right)
- Command palette (⌘K / Ctrl+K from anywhere)
- Metrics with Overview, Revenue & Demand, Follow-up Queue, Call Handling, Caller Sentiment
- Conversations table with multi-select filters
- Conversational "Ask AI" surface

## Run locally

Just double-click `index.html`. No build step, no install — everything is a single file using CDN-hosted React, Recharts, and Tailwind.
